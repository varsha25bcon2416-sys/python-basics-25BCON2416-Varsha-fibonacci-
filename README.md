
# Fibonacci Python Program

## Description
This program generates the Fibonacci sequence for a given number of terms.

## Features
- Accepts the number of terms from the user.
- Generates the Fibonacci sequence.
- Displays the sequence as output.

## Requirements
- Python 3

## How to Run
Run the following command:

python fibonacci.py

## Example Output
0 1 1 2 3 5 8
